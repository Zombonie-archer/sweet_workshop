# 🍰 Солодка майстерня (Sweet Workshop)

Веб-ресурс кондитерської майстерні з можливістю перегляду каталогу десертів, фільтрації за категоріями, ознайомлення з відгуками та оформлення замовлення онлайн.

---

## 📌 Про проєкт та його призначення

**«Солодка майстерня»** — це сучасний веб-сайт для кондитерської, створений з метою зручного вибору та замовлення авторських солодощів ручної роботи (десерти, торти, випічка).

### Основні можливості та функціонал:
* 📱 **Адаптивна верстка**: повноцінна підтримка трьох точок перелому (Mobile, Tablet, Desktop) та оптимізація під Retina-екрани.
* 🍰 **Каталог десертів**: фільтрація за категоріями (*Гарячі десерти, Французькі тістечка, Класичні торти, Школадні випічки, Фруктові десерти* тощо) та кнопка довантаження додаткових карток («Завантажити ще»).
* 🔍 **Модальне вікно товару (Product Modal)**: перегляд детального складу десерту, ціни та рейтингу.
* 🛒 **Оформлення замовлення (Contact Modal)**: зручна форма для відправки заявки з валідацією полів (*Ім'я, Телефон, Коментар*).
* 🎠 **Інтерактивні слайдери**:
  * Слайдер секції **«Про нас»** (галерея процесу виготовлення).
  * Слайдер секції **«Відгуки клієнтів»** із відображенням зоряного рейтингу.
* ❓ **Часті питання (FAQ)**: інтерактивний аккордеон із відповідями на популярні запитання клієнтів.
* 🔔 **Сповіщення та лоадер**: спливаючі повідомлення про статус замовлення та глобальний індикатор завантаження.

## 🛠 Використані технології

### **Core Stack:**
* **HTML5** (Семантична верстка, модульна структура з `vite-plugin-html-inject`)
* **CSS3** (Сучасні методи стилізації, адаптивні сітки, оптимізація через PostCSS)
* **JavaScript (ES6+)** (Модульна архітектура, асинхронні запити, інтерактивність)

### **Збірник та інструменти:**
* **[Vite](https://vitejs.dev/)** — бандлер для швидкої збірки та розробки
* **Git / GitHub** — система контролю версій та командна розробка

### **Бібліотеки та залежності:**
* **[Swiper.js](https://swiperjs.com/)** — реалізація слайдерів (секції «Про нас» та «Відгуки»)
* **[Accordion-js](https://github.com/skyl3r/accordion-js)** — інтерактивний блок FAQ
* **[Axios](https://axios-http.com/)** — обробка HTTP-запитів
* **[iziToast](https://izitoast.marcoslourenco.com.br/)** — стильні сповіщення для користувача
* **[css-star-rating](https://www.npmjs.com/package/css-star-rating)** — візуалізація рейтингу оцінок
* **[modern-normalize](https://github.com/sindresorhus/modern-normalize)** — кросбраузерне скидання стилів

## 🚀 Як запустити / розгорнути проєкт

### **Передумови**
Переконайтеся, що у вас встановлено [Node.js](https://nodejs.org/) (версії 18+ або новіше).

### **Кроки для локального запуску:**

**1. Клонуйте репозиторій:**
   ```bash
   git clone [https://github.com/Zombonie-archer/sweet_workshop.git](https://github.com/Zombonie-archer/sweet_workshop.git)
   cd sweet_workshop
   ```

**2. Встановіть залежності:**
   ```bash
   npm install
   ```
**3. Запустіть режим розробки:**
  ```bash
   npm run dev
   ```
Після цього проєкт буде доступний за адресою http://localhost:5173/ (або іншою, вказаною в терміналі).

**4. Збірка для продакшену (Build):**
  ```bash
   npm run build
   ```
Готові оптимізовані файли будуть збережені в папці dist/.

**5. Попередній перегляд збірки (Preview):**
  ```bash
   npm run preview
   ```
